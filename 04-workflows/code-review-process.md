# Code Review Process

## For Authors
- Keep PRs small (< ~400 lines where possible)
- Write a clear description: what & why
- Self-review before requesting others

## For Reviewers
- Respond within 1 business day
- Check: correctness, readability, tests, security (no secrets!)
- Approve, or request changes with actionable comments

## Approval
- 1 approval required to merge
- CI must pass
