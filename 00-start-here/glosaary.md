# 📖 Glossary

| Term | Meaning |
|------|---------|
| **ADR** | Architecture Decision Record — a short doc capturing a decision and its rationale |
| **RAG** | Retrieval-Augmented Generation — AI answers using your docs as source |
| **MuleSoft / Anypoint** | Integration platform sitting between the portal and data sources |
| **PAT** | Personal Access Token — GitHub credential used by MuleSoft |
| **ContentProvider** | Our abstraction layer so storage (GitHub/SharePoint) is swappable |
| **Portal** | The UI where team members browse and search project info |
