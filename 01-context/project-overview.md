# Project Overview

## What
A lightweight internal portal that centralizes all project information —
context, decisions, architecture, and docs — with built-in search and AI chat.

## Why
New team members and stakeholders spend too long hunting for information across
scattered sources. This gives one place to find or ask for anything.

## Goals
- Single source of truth for project knowledge
- Fast onboarding for new joiners
- AI chat to answer questions with cited sources
- Storage-agnostic (GitHub now, SharePoint later via MuleSoft)

## Success Criteria
- A new joiner can self-serve answers without interrupting the team
- Docs stay current (owned, reviewed)
